## What it does

`main.ts` (Node 22, no dependencies, no network) writes one one-line joke
about working beside an AI coding agent to `/output/entry.txt`:

> My agent live-demoed a feature that doesn't exist, and the room applauded the hallucination.

## Run

```sh
node main.ts
```

This writes `/output/entry.txt` (UTF-8, one line, under 280 characters).
